# PID implementation scripts

The scripts in this repository are related to the Ecosystem Indicators Workflows PID implementation plan.

These scripts are intended to help in the preparation of outputs and metadata, uploads, queries, etc.

## Zenodo

Use zenodo for versioned datasets

## UNSWorks

For mature outputs that won't require version control

## W3ID

For stable online resources, such as the vocabularies.
